# 导入样例说明（复杂版）

## 文件清单
- `trip-import-validation-client.csv`：客户端验收样例（12 行，均为 **20 天行程**，故意留空领队字段用于校验流程）。
- `trip-import-validation-internal.csv`：内部联调用样例（12 行，字段完整，可直接导入）。

## 前端上传位置
1. 打开前端后进入左侧菜单 **Trips / 行程管理**。
2. 在页面右上角点击 **Excel导入**。
3. 选择 `docs/import-samples/` 下任一 CSV 文件上传。
4. 上传后点击具体团进入 **导入校验** 标签页核对识别结果。

## 适用场景
- 需要验证多团并行导入。
- 需要验证长周期（20 天）行程导入后的校验与补全体验。
- 需要验证“缺失字段”在导入校验页中的展示。
