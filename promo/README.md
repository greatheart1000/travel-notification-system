### 小红书

导游的早晨，不应该从几十条群消息开始。

我们把旅行社的行程通知做成了一个工作台：

行前提醒 / 早间集合 / 午间休息 / 晚间预告 / 行后回访，
按时间自动排好；
每个团可以自动发送，也可以等导游确认；
管家、司导、司机还能分岗位发送。

管理员能看到每位导游负责哪个团、实际发了什么、有没有送达。
天气突变时，游客通知和内部协同也一起准备好。
