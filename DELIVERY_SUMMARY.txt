## 🎯 功能模块详解

### 📊 仪表盘 (Dashboard)
**首页，展示系统概览**
- 📈 4 个关键指标卡片
- 📋 最近通知列表
- 🎨 彩色图标和数据可视化

**技术特点：**
- 响应式卡片栅格
- 实时数据更新（未来集成 WebSocket）
- 统计数据聚合

### 🗺️ 行程管理 (Trips)
**完整的 CRUD 行程管理**
- ➕ 创建新行程
- ✏️ 编辑行程信息
- 🗑️ 删除已完成行程
- 📱 卡片式响应布局

**数据字段：**
```typescript
{
  id: string
  destination: string      // "乌鲁木齐-喀什"
  team_id: string          // "TEAM-001"
  start_date: string       // "2026-04-15"
  end_date: string
  participants: number     // 参加人数
  status: string           // "进行中" | "计划中" | "已完成"
}
```

### 🔔 通知中心 (Notifications)
**通知模板和发送历史管理**
- 📄 创建通知模板
- 🎨 动态变量支持 `{{variable}}`
- 📤 测试发送通知
- 📊 发送统计和成功率
- 📋 快速复制模板

**支持的通知渠道：**
- 📱 短信 (SMS)
- 🟢 企业微信
- 📧 邮件 (Email)

### ⚙️ 偏好设置 (Preferences)
**用户个性化系统配置**
- 📢 启用/禁用通知渠道
- 🕐 静默时段设置 (22:00-08:00)
- 📊 频率限制 (每小时最大通知数)
- 🔧 高级功能开关
  - 自动升级高风险投诉
  - 聚合相同类型通知

### 📈 数据分析 (Analytics)
**系统性能和用户数据分析**
- 📊 关键指标卡片
  - 通知成功率
  - 平均响应时间
  - 周环比增长
  - 用户满意度

- 📉 渠道性能对比表
  - 各渠道发送量
  - 成功/失败数
  - 成功率排序

- 🏆 热门行程排行
  - 通知数排序
  - 用户满意度评分
  - 星级评级

## 🔌 API 集成

### 预期的 API 端点

```typescript
// 仪表盘
GET /api/dashboard/stats
GET /api/notifications/recent

// 行程管理
GET    /api/trips
POST   /api/trips
PUT    /api/trips/:id
DELETE /api/trips/:id

// 通知管理
GET    /api/notifications/templates
POST   /api/notifications/templates
PUT    /api/notifications/templates/:id
POST   /api/notifications/send-test
GET    /api/notifications/history

// 偏好设置
GET  /api/preferences
PUT  /api/preferences

// 数据分析
GET /api/analytics/metrics
GET /api/analytics/channels
GET /api/analytics/trips/ranking
```

### 数据流向

```
用户界面 (React)
    ↓
Axios HTTP 客户端
    ↓
Vite 代理 (/api → http://localhost:8000)
    ↓
后端 API 服务
    ↓
业务逻辑处理
    ↓
数据库查询
    ↓
响应 JSON
    ↑
页面自动刷新和数据绑定
```
